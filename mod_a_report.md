# Отчёт о выполнении модуля А
## 1. Цель работы
извлечение данных о компетениях и связанных с ними событиях из HTML-страница,сопоставление с таблицами и загрузка результатов в PostgreSQL

## 2. Использованные источники
В работе использованы исходные CSV-таблицы:
- `base_events.csv` — сведения о событиях;
- `base_regions.csv` — справочник регионов;
- `base_fact_results.csv` — результаты;
- `base_news_text.csv` — новостные тексты;
- `base_competency_text_full.csv` — полные тексты компетенций;
- `ref_stage_type.csv` — справочник типов этапов.
Дополнительно использованы HTML-страницы реестра компетенций и карточек отдельных компетенций.

## 3. Извлечение данных из HTML
Для обработки HTML разработан Python-скрипт `src/parse_competencies.py`.
С помощью библиотек BeautifulSoup и pandas выполнены следующие действия:
- извлечение идентификаторов и названий компетенций;
- извлечение категорий и названий ведущих регионов;
- извлечение описаний и текстовых статусов;
- извлечение ссылок на связанные события;
- сопоставление страниц событий с идентификаторами из исходной таблицы событий.

Результаты сохранены в CSV-файлы:
- `stg_competency_html.csv` — 318 записей;
- `stg_competency_event_link.csv` — 916 записей.

## 4. Загрузка и преобразование данных
Исходные CSV-таблицы и результаты HTML-парсинга загружены в схему `rep1` базы данных PostgreSQL.
Для обогащения результатов использована таблица `stg_fact_results_enriched`.
Сопоставление компетенций выполнено по полю `comp_id`. Для формирования итоговой таблицы использовано соединение `LEFT JOIN`, позволяющее сохранить исходные записи результатов и дополнить их атрибутами из HTML.
Дополнительно сформирована таблица связей компетенций и событий `stg_competency_event_link`, содержащая 916 записей.

## 5. Контроль качества
Выполнены проверки:
- количества записей и уникальности `result_id`;
- заполненности обязательных идентификаторов;
- соответствия результатов исходным событиям;
- соответствия результатов справочнику компетенций;
- соответствия результатов справочнику регионов;
- корректности связей компетенций и событий.
В итоговой таблице получено 11 790 записей с уникальными идентификаторами результатов.
Количество несопоставленных записей по событиям, компетенциям и регионам — 0.
Количество несопоставленных связей компетенций и событий — 0.

## 6. Итог
В рамках модуля А:
- изучены исходные таблицы и HTML-структура;
- разработан скрипт извлечения данных из HTML;
- сформированы справочник компетенций и таблица связей компетенций с событиями;
- данные загружены в PostgreSQL;
- сформирована обогащённая таблица результатов;
- выполнены проверки качества данных.
Основные результаты модуля А подготовлены в базе данных PostgreSQL в схеме `rep1`
