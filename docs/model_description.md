# Описание модели данных- модуль А

## 1. Назначение
Модель данных предназначена для подготовки аналитического слоя по результатам чемпионатов профессионального мастерства. Она объединяет сведения о компетенциях, мероприятиях и результатах участников.

## 2. Источники данных
- HTML-карточки компетенций — сведения о компетенциях и ссылки на мероприятия.
- `base_fact_results.csv` — результаты участников.
- `base_events.csv` — справочник мероприятий.
- `base_regions.csv` — справочник регионов и организаций.

## 3. Таблицы
### stg_competency_html

Содержит сведения о компетенциях, извлечённые из HTML-карточек.

- Количество записей: 318.
- Первичный ключ: `comp_id`.
- Основные атрибуты: название, категория, регион-лидер, описание, статус, комментарий, путь к исходной HTML-странице.

### stg_competency_event_link

Содержит связи между компетенциями и мероприятиями, извлечённые из HTML.

- Количество записей: 916.
- Составной первичный ключ: `comp_id`, `event_id`.
- Сопоставление с мероприятиями выполнено по точному совпадению `source_page`.
- Метод сопоставления: `source_page_exact`.

### stg_fact_results_enriched

Содержит результаты участников, обогащённые сведениями о компетенциях.

- Количество записей: 11 790.
- Первичный ключ: `result_id`.
- Содержит идентификаторы мероприятия, компетенции и региона, место, признак медали, вес результата и атрибуты компетенции.
- Метод сопоставления HTML: `source_page_exact`.

## 4. Ключи и связи
- `comp_id` идентифицирует компетенцию.
- `event_id` идентифицирует мероприятие.
- `region_id` идентифицирует регион или организацию.
- `result_id` идентифицирует отдельную запись результата.
- `source_page` используется для сопоставления HTML-ссылок с мероприятиями.

Связи компетенций и мероприятий формируются через таблицу `stg_competency_event_link`.

## 5. Результаты проверок
- Извлечено 318 карточек компетенций.
- Получено 916 уникальных связей компетенция–мероприятие.
- Подготовлено 11 790 обогащённых результатов.
- Пропуски в ключевых атрибутах после объединения не обнаружены.
- Дубликаты ключей не обнаружены.
- Все 11 790 результатов имеют подтверждённое HTML-сопоставление.

## 6. Ограничения
Поле региона/организации в исходном справочнике содержит не только географические регионы, но и организации. Для последующей аналитики необходимо учитывать это различие.
