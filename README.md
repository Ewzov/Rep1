# Модуль А

## Цель
извлечение данных о компетениях и связанных с ними событиях из HTML-страница,сопоставление с таблицами и загрузка результатов в PostgreSQL

## Структура данных
схема rep1

### Исходные таблицы
- `raw_base_events` - события
- `raw_base_regions` - регионы
- `raw_base_fact_results` - результаты
- `raw_base_news_text` - новостные тексты
- `raw_base_competency_text_full` - полные текста компетенций
- `raw_ref_stage_type` - справочник типов этапов

### Промежуточные таблицы
- `stg_competency_html`: справочник компетенций, извлечённый из HTML
- `stg_competency_event_link`: связи компетенция - событие по HTML-ссылкам

### Итоговая таблица
- `stg_fact_results_enriched`: факт результатов, обогащённый HTML-атрибутами компетенции

## Логика обработки
1. HTML-страницы разбираются скриптом parse_competencies.py
2. Извлеченные данные сохраняются в csv
3. scv-файлы загружаются в промежуточные таблицы PostgreSQL
4. Компетенции сопоставляются по comp_id
5. Связи компетенций и событий определяются по comp_id и event_id
6. Итоговая таблица формируется запросом с left join

## Проверки качества
Были проверены: заполненость обяз. полей, уникальность идентификаторов, отсутствие дубликатов, корректность связей с событиями, регионами и компетенциями. Все записи сопоставлены, нет несопоставленных
